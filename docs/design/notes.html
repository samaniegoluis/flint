Shortcut mapping

Mapping only ⌘ → Ctrl+Shift turns ⇧⌘K (Keys) and ⌘K (palette) into the same Linux chord, and likewise ⇧⌘C vs ⌘C. Proposed rule: ⌘ → Ctrl+Shift, ⇧⌘ → Ctrl+Alt+Shift. The alternative is to drop the rail shortcuts on Linux and use the palette.

⌘1–9 switch tabs only. Vaults switch through ⇧⌘O and the palette, never digit shortcuts. Rail: ⇧⌘H, ⇧⌘K, ⇧⌘C, ⌘,. The full table is in screen 12c and in the README.

Focus order

  1. Title-bar palette button
  2. Activity bar (one Tab stop; ↑↓ between Hosts, Files, Keys, Credentials, Settings)
  3. Sidebar view — Hosts: vault button, filter, tree (↑↓ move, ←→ fold, ↵ connect, ⌘↵ new tab, ⌘I edit) · Files: path bar, file list, transfer queue
  4. Tab bar (one Tab stop; ←→)
  5. Session toolbar
  6. Terminal (keeps Tab for the shell)
  7. Status bar

F6 / ⇧F6 cycles regions, so keyboard users can always leave the terminal.

Hover, active, focus-visible

  • Hover: --surface-hover, text raised to primary, 120 ms ease-out.
  • Active: --surface-active; primary buttons use --accent-press.
  • Focus-visible: keyboard only — 2 px base gap and a 2 px accent ring (--focus-ring). Mouse focus shows nothing.
  • Inputs: accent border plus a 3 px glow on focus; danger border, glow and a linked message on error.
  • Disabled: 45 % opacity. Controls with a reason (Split, a credential in use) stay focusable with aria-disabled and show their tooltip.

Sidebar views & collapse

  • The activity bar's top group switches one sidebar slot: Hosts (⇧⌘H) or Files (⌘E). Keys and Credentials open full-page views and hide the sidebar.
  • Clicking the already-active view hides the sidebar, and clicking it again restores it. ⌘B does the same. While hidden, the item keeps its ember tint without the fill.
  • Each view remembers its own width: Hosts is 264 px (200–400), Files is 340 px (200–480). Drag the right edge to resize; a double-click resets it.
  • Below about 1040 px of window width, the sidebar starts hidden and opens as an overlay over the terminal; esc or clicking outside closes it (screen 04c, 900 × 600).
  • Width changes animate over 240 ms (--dur-slow), instantly under reduced motion. The right side of the window stays free for the agent activity panel.

Prompts over the terminal

  • Password, passphrase and host-key prompts belong to their tab, not the window. They render inside the pane over --pane-dim, and other tabs keep working.
  • The tab shows a short accent label (“needs input”, “verify host”). For a background tab, a toast says “prod-api-02 needs your input ⌘2”.
  • Focus moves into the prompt when its tab is active. ↵ runs the primary action; esc cancels the attempt.
  • Host key changed has no ↵ default. Replace turns on only after the user types the host label; “Close session” gets initial focus.
  • Session cards (connecting, auth failed, connection lost) use the same layer. The dimmed scrollback stays visible and survives a reconnect.

Files view (SFTP)

  • Files belongs to the active tab's session, and its header reads “Files · <host label>”. When you switch tabs it follows, keeping each session's last folder and scroll position.
  • Without a connected session, it shows “Open a session to browse its files” with Reconnect or Go to host (screen 14c).
  • Path bar: .. (⌘↑), a breadcrumb, and a crosshair that syncs to the terminal's folder (OSC 7). Below it: Upload and New folder.
  • The context menu offers Download, Rename, Copy path, New folder and Delete.
  • Dragging files from the OS turns the whole sidebar into the drop target and shows the remote path. Existing files ask before they're replaced.
  • The transfer queue is docked at the bottom of the sidebar, with per-file progress and cancel. “Clear done” keeps failed items with Retry, and the queue collapses when empty.

Kept out of the MVP

  • Splits — the Split button is visible but disabled, with a “coming soon” tooltip.
  • Saved workspaces and session restore.
  • Per-host health, status dots or latency in the tree. Latency appears only in the session toolbar and status bar.
  • Agent tokens and the rail item. Caller approval and Settings › Access arrive in v3 (milestone 12) and are designed on page 05, which replaces the old wireframe 15.
