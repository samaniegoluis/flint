:::caution[Early development]
Flint works today as a desktop app and as the `flint` CLI, over the same encrypted vault.
SFTP, tunnels, an SSH agent and the MCP server are next. Build it [from
source](/start/build-from-source/).
:::

<CardGrid>
	<Card title="One encrypted vault" icon="seti:lock">
		Hosts, keys and credentials live in a single SQLite file that is encrypted in full.
		Put it in any cloud-synced folder; nothing about your servers is readable on disk.
	</Card>
	<Card title="GUI and CLI, same core" icon="laptop">
		A desktop app with tabs and a modern terminal, and a `flint` command that drives the
		same vault, with `--json` on every command.
	</Card>
	<Card title="Built in cfire" icon="open-book">
		Flint is written in [cfire](https://github.com/gsandoval/cfire), a Go-flavoured
		language that compiles to C++23.
	</Card>
</CardGrid>
